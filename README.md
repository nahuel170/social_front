# Social App — Frontend

Frontend de una aplicación social desarrollado con **React**, **Redux Toolkit** y **Vite**. Forma parte de un proyecto full stack con un servidor Node.js independiente.

## Tecnologías
- React 18 y React Router
- Redux y Redux Toolkit
- JavaScript y Vite
- Socket.IO Client
- Semantic UI React

## Arquitectura del proyecto
- `src/components`: componentes de la interfaz.
- `src/router`: navegación.
- `src/store`: manejo del estado.
- `src/socket.js`: integración con la comunicación en tiempo real.

## Ejecutar localmente
```bash
npm install
npm run dev
```

Es necesario disponer de la API correspondiente y configurar las variables de entorno localmente cuando sean requeridas.
